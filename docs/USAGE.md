# 使用说明

## Android

1. 安装 `VDAT-Converter-Android.apk`。
2. 在“保存位置”中选择 MP4 输出目录，默认保存到 `Download/VdatConverter`。
3. 在“来源类型”中选择“VDAT 视频目录”或“.vdat 视频文件”。
4. 选择视频来源。选择视频目录时，选择下载出来的 `.vdat` 视频目录即可，程序会自动识别内部的分片目录。
5. 输出文件名会自动使用来源名称，也可以手动修改。
6. 点击“开始转换”。转换完成后，可点击“查看转换后的视频”直接打开 MP4。

几 KB 的 `.vdat` 通常是播放列表或元数据，不是完整视频。遇到这种文件时，请改选对应的视频目录。

## Windows

1. 解压 `VDAT-Converter-v1.0.1-windows-x64.zip`。
2. 运行 `VDAT-Converter.exe`。
3. 选择 `.vdat_contents` 目录，或选择包含多个 VDAT 视频目录的上级目录。
4. 选择输出目录。
5. 点击“开始转换”。完成后程序会询问是否打开输出目录，也可以随时点击“打开输出目录”。

Windows 发布版已经内置 FFmpeg，不需要额外下载或把 `ffmpeg.exe` 放到旁边。

## 支持的来源

- VDAT 视频目录：目录内包含 `0.key` 和数字分片。
- 完整 `.vdat` 视频文件：文件头是 MP4，程序会直接保存为 `.mp4`。

本工具只处理你拥有或获授权的视频文件。
